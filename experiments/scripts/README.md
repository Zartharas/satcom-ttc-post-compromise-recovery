# Experiment Scripts

Current paper-facing scripts:

- `run_paper_final_experiment.py` — validates the committed final plan and executes Studies A-D;
- `summarize_paper_final_results.py` — verifies the retained bundle and derives tracked
  manuscript-facing result sources.

Phase-numbered runners and validators are retained for reproducibility of the development,
formal-assurance, and Phase 15 evidence chain. They are historical/supporting tools rather than
the active manuscript task queue.
