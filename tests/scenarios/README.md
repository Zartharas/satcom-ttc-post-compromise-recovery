# Scenario Catalogs

This directory contains deterministic design and development scenario catalogs for B0-B2, T1,
and earlier fault/analysis/formal phases.

These catalogs are **design oracles and reproducibility inputs, not empirical findings**.

The final paper Study B/C/D schedule population is defined separately in
`experiments/configs/paper-final-experiment.json`. Historical phase catalogs remain unchanged for
provenance.
