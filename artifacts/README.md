# Artifacts

This directory contains tracked integrity manifests and release-policy notes.

`artifacts/manifests/repository-v0.1.1.sha256` is the tracked-file integrity manifest used by
repository validation.

Large retained experiment bundles are not committed here. Their exact run identity and SHA-256
are recorded in `paper/RESULTS_SUMMARY.md`; a future public archive or GitHub Release may carry
the packaged bundle when the manuscript/release is ready.
